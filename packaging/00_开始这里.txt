Outlook / PST / MSG 邮件转 Markdown — Windows 便携版

怎么使用
1. 把整个 ZIP 解压到一个普通本地文件夹，不要在压缩包里面直接运行。
2. 双击 Start.bat，打开中文窗口。可右键 Start.bat → 发送到 → 桌面快捷方式。
3. 选择来源、时间、保存位置和导出内容，先预览，再开始。
4. 需要继续时选择相同保存位置；保留归档中的 state、indexes、logs。
5. 程序结束会显示结果弹窗和顶部提示。更详细的操作见“一页中文使用说明.md”。
运行条件
- Windows 10/11，64位。已附独立 Python 及依赖，无需 VS Code、无需安装 Python。
- 需要本机安装并配置好“经典 Outlook”。仅有新版 Outlook 不满足条件。
- PST 原件应保留。首次工作副本需要与 PST 相当的额外磁盘空间。
- 首次换电脑使用，先选最多5封样本验证，再处理大范围。
- 本包没有数字签名。若被公司安全策略拦截，请交由 IT 核查，不要关闭安全软件。

哪些东西分别保存
- 此程序 ZIP：长期保存一份供自己使用。推荐向同事分享官方发布页链接；再发布程序包须取得书面许可。整个解压文件夹可以搬家。
- 原始 PST：邮件原件，单独备份，勿放入共享程序包。
- MD-Archive：最终邮件成果，连同状态和报告整体保存。
- PSTWork：工作副本，转换完成并核对后可按需清理；以后可能需要重新复制。
- 本机上次选择记录存于 %LOCALAPPDATA%\OutlookEmailArchiver，不包含在本发布包中。

以后不用时怎么处理
保留带版本号的程序 ZIP、源码 ZIP、SHA256SUMS.txt 和测试说明，另存一份到其他磁盘。
无需卸载，也不需要让程序常驻后台。下次解压并双击即可。
分享时推荐发送官方发布页链接；不要发送 PST、MD-Archive、PSTWork 或本机运行记录。
源码包供以后修复/开发；普通使用者只需要便携版。
源码与所用第三方运行库的授权分别适用；第三方许可证保留在 runtime 中。
